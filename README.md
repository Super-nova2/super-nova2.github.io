# Bingzhou Gao — Personal research homepage

Live site: https://super-nova2.github.io/

English static homepage for AI, scientific discovery, and astronomy research.

## Editing

- `index.html`: content, education, research interests, and project links.
- `styles.css`: layout, typography, and responsive styles.
- `.nojekyll`: serve the static site without Jekyll processing.

GitHub Pages publishes the root of the `main` branch. Updates to these files trigger publication automatically.

## Privacy

This repository contains only the sanitized website. The source CV, private contact details, grades, private research data, credentials, and local runtime files are excluded. There are no tracking scripts, analytics, external fonts, or contact forms.
